# Anki 助手 · 更新日志

这个文件记录每一次版本更新改了什么。

- 它就在工程根目录（`AnkiAssistantAndroid\CHANGELOG.md`），`build.ps1` 会把它拷进 `assets\CHANGELOG.md` 打包进 APK，
  所以 **App 里点「设置 → 查看更新内容」离线也能看**，不需要联网。
- 版本号只有一个来源：`src\com\ankiassistant\Version.java` 的 `VERSION_TAG`；
  `build.ps1` 从它推导 manifest 里的 `versionName` / `versionCode`，所以 APK 显示的版本永远不会和代码对不上。
- 每次迭代：先改这个文件新增一节，再把 `VERSION_TAG` 加一档，然后构建。

## v1.6.0 · 2026-10-03 —— 内置 AI Key（密文）

### 新增
- **内置智谱 Key（密文形式）**：新设备装完直接能用 AI，不用再手输 Key
  - APK 里只有 AES-GCM 密文，没有明文；密钥由「口令 + 随机 salt」经 PBKDF2-HMAC-SHA256（12000 轮）派生
  - 口令不写成完整串，拆成 4 段放在不同方法里，其中一段反序存放 —— 直接 `strings` 扫 APK 拿不到
  - 生成/更换方式：`java tools/MakeSecret.java <新Key> <新口令>`，把输出的三行粘进 `Secret.java`
- **手填优先**：设置里填过的 Key 优先于内置 Key（`Store.aiApiKeyFor`），
  发现异常随时在设置里换一把，不用重新发版
- 设置页 AI Key 输入框的提示改为「留空则用内置 Key」

### 安全说明（必须知道）
- 只要密钥随 APK 分发，**一定能被逆向出来**；加密只是把「随手提取」提高到「需要真正逆向」
- 因此**故意的取舍**：仓库/Release 是公开的，所以
  1. 只内置了智谱这把**免费档** Key；付费余额的 Key（如 DeepSeek）**不打包**，
     要加就用上面那条命令单独生成（泄露代价由你自己权衡）
  2. 智谱后台随时可以**吊销/重建**这把 Key：换完重新生成密文、发个新版即可
  3. 真要做到"完全不可提取"，只能把 Key 放在自己的服务端做代理转发（本项目不走这条路）

## v1.5.2 · 2026-10-03 —— 把基本设置内化进程序

  学科背景 `CIE A-Level / NCUK IFY 数学、物理术语`、保存后自动同步 AnkiWeb 开启、
  思考模式关闭、牌组→标签映射（数学类 → `ALevel::Maths`，物理 → `ALevel::Physics`）

### 说明（有意不内置）

  任何人都能提取并消耗额度。新设备上填一次即可（智谱的 Key 与 DeepSeek 的 Key 会分别记住）

## v1.5.1 · 2026-10-03 —— 更新日志改为在线读取（与 StudyCompanion 一致）

### 调整
- 更新日志的读取方式改成与 StudyCompanion **完全一致**的三级优先级：
  1. 从 GitHub 拉下来的缓存（应用私有目录里的 `CHANGELOG.md`）
  2. 打包进 APK 的 `assets/CHANGELOG.md`
  3. 都读不到才提示（正常情况下不会发生）
- 打开「查看更新内容」时**先联网拉最新日志**（`raw.githubusercontent.com`，匿名可读、不需要令牌），
  成功就写进缓存；拉不到就用缓存/内置副本，**并在标题下写明来源**：
  「来自 GitHub 最新版（缓存于 MM-dd HH:mm）」或「来自应用内置副本（离线）· 在线更新失败：<原因>」
- 好处：以后改完日志不用重新装 APK 也能看到最新内容（旧版本同样受益）

## v1.5.0 · 2026-10-03 —— 自动更新（GitHub Release）

### 新增
- **设置 → 更新内容 → 检查更新**：匿名查 GitHub 最新 Release，和本机版本做数值比较
  （2.1.10 > 2.1.9 这种不会再判错），有新版本就弹出更新说明
- **一键下载并安装**：APK 下到 `cache/update/`，通过自实现的 `ApkProvider`（content://）
  交给系统安装器；Android 8+ 未授权时会先跳转「安装未知应用」设置页
- 新增 `Updater.java`（查 Release / 比对版本 / 下载）、`ApkProvider.java`、
  `REQUEST_INSTALL_PACKAGES` 权限；仓库是公开的，**查更新与下载都不需要登录、不需要令牌**
- 工程本身已上传到 GitHub：`https://github.com/RenataZero0/AnkiAssistant`，
  每次发版在 Releases 里附上 APK 即可被旧版本检查到

### 说明
- 只做"检查 + 下载 + 交给系统安装器"，不做静默安装（那需要 root 或设备管理员权限）
- 仓库地址写在 `Updater.OWNER / Updater.REPO` 两行，换仓库只改这两行

## v1.3.0 · 2026-10-03 —— 牌组标签联动 + 编辑区内嵌面板

### 新增
- **牌组 → 标签自动映射**：四个数学牌组（Pure Mathematics / Mechanics / Probability & Statistics / Further Mathematics）
  自动带出 `ALevel::Maths`，`A Level Physics` 自动带出 `ALevel::Physics`，其它牌组不动用户填的标签。
  映射表只有 `CardFormat.tagsForDeck()` 一份
- **牌组 / 标签 / 「从 Anki 选择」/ 保存按钮搬进编辑区内部**（`assets/editor.html` 的 `#metaPane`），
  跟着字段一起滚动，不再固定占一块面板；通过 `editor.addJavascriptInterface(bridge, "Android")`
  回调 Java（`pickDeck` / `saveNote` / `saveDraft` / `tagForDeck`），编辑区因此多出约 150dp 高度
- 侧栏底部新增 **Anki 连接状态灯**（绿=连得上 / 红=连不上 / 黄=检测中），启动自动测一次，
  点一下重新检测，设置保存后也会复测

### 修
- **编辑区顶部工具栏滚动时抖动**：`编辑/预览` 和工具栏原来是两个各自 `position: sticky` 的元素，
  用硬编码 `top: 48px` 拼在一起，tab 实际高度一变就互相追着重排。
  现在合并成同一个 `#topSticky` 容器，再加 `translateZ(0)` 提升为合成层
- **设置页勾选框与文字不在同一行**：改用「方块 + 独立文字」的一行 + 整行 `CENTER_VERTICAL`，
  两者中心由布局保证重合（多行文字也不会歪）
- **预览里的空状态**：没输入单词显示「还没有输入单词」，没有内容显示
  「还没有内容 · 点上方「AI 填充」自动生成，或切到「编辑」自己写」，不再是空白卡片

### 调整
- 预览页移除「夜间模式」（连同一整套 `body.night` 样式）
- 编辑区灰色占位文字全部换成**纯格式说明**（如 `英 /…/；美 /…/`），
  去掉原来那些编造的示例内容（假的音标 `/ˈprɒbəbəl/`、假的释义 `(n) English definition`）
- 修复提示词里的「输出示例」：原来少一个引号（`confusables"`），模型会照着坏示例写；
  现在示例本身是合法 JSON，并且【易混】示例改成新格式（英文词性、不带破折号）

## v1.2.0 · 2026-10-03 —— 思考模式与解析加固

### 新增
- 服务商预设升级为 **智谱 GLM-4.5-Flash（免费）**：同一提示词实测明显优于 glm-4-flash
  （音标标准、释义准确、公式自带 `\(...\)` 定界符）
- **每个服务商各存一把 API Key**，切换服务商时自动带出，不用反复粘贴（旧版本的单一 Key 自动迁移到当前服务商名下）
- **「让思考型模型先思考」开关**（默认关闭）：开启时思考内容显示在制卡页的
  「AI 思考过程（N 字）」折叠面板里，默认只有一行，点开是限高滚动区
- AI 生成中的反馈：按钮变「生成中…」并禁用、状态行转圈、文案写明预计耗时

### 修
- **思考模式实测反而更差**：glm-4.5-flash 开思考 23 秒、思考 1279 字，
  还会把输出预算吃掉导致 JSON 被截断；关闭后 4.5 秒且一次成型。所以默认关闭
- AI 超时 60 秒 → 180 秒（免费档思考型模型实测要 50～65 秒）
- **解析加固**（实测模型会写坏 JSON）：
  - `repairJson()` 修全角冒号、键后丢引号的坏 JSON（只动"键+冒号"，不碰值里的中文标点）
  - `looseExtract()` 语法实在修不好时按字段名硬抠
  - 公式兜底：裸 LaTeX 自动补 `\(...\)`，`$...$` / `$$...$$` 统一转成 `\(...\)` / `\[...\]`
  - 解析失败自动重试一次（改用严格提示词并强制关思考），再失败才降级成"原样放进定义"

## v1.0.0 · 2026-10-03 —— 初版

### 新增
- 无 Gradle 构建链：`aapt2` → `javac` → `d8` → `zipalign` → `apksigner`（沿用 StudyCompanion 的工具链约定）
- **卡片格式**：正面只有单词；背面按固定格式渲染
  （音标 / 词性 / 定义 / 关联公式 / 易混 / 中文），关联公式用行内 MathJax `\(...\)`
- **AnkiConnect 集成**：自动建牌组、自动建「专业术语卡」笔记类型、`addNote` 后 `changeDeck` 兜底、
  保存后自动 `sync()` 推到 AnkiWeb
- **AI 自动填充**：OpenAI 兼容接口，内置 DeepSeek / 豆包 / 智谱 / 硅基流动 / 自定义预设，APK 内不内置任何 Key
- **编辑器**：`assets/editor.html`（ES5，WebView 内跑），支持加粗/斜体/下划线/颜色/列表/引用/行内代码/
  挖空 `{{c1::}}`/行内与独立公式/撤销重做/HTML 源码编辑；预览用真正的卡片模板渲染（与桌面端 Anki 同款）
- **MathJax 3.2.2 离线内置**：23 个 woff 字体随 APK 打包；用应用内的本机小服务器（`AssetServer`）喂给 WebView
- **浏览页**：云端 / 本地草稿两个分页、按牌组筛选、Anki 搜索语法、卡片详情预览、删除、`guiEditNote`、同步
- **设置页**：Anki 连接 + 六步配置向导、AI 服务商/Key/模型/地址、默认值、导出草稿、崩溃日志
- **本地草稿兜底**：Anki 连不上时自动转存草稿箱，卡片不会丢

### 已知坑（都已在代码里注释）
- Windows 上 aapt2 会把嵌套 assets 的路径写成反斜杠，`AssetManager` 打不开 → assets 保持扁平 + `AssetServer` 做映射
- 本机小服务器必须先读完整个请求头再响应，否则 TCP RST 会把页面截断
- AnkiConnect 插件配置文件不能带 UTF-8 BOM，否则插件启动失败
